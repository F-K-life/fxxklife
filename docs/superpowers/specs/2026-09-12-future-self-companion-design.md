# “高我”陪伴型 AI 手机 Demo 设计

## 目标

构建一个只有前端的黑客松 Demo，让新用户在几分钟内体验到：AI 先倾听、再求证、允许用户纠正，最后给出一个与用户价值观一致的小行动。产品的核心不是“看穿你”，而是“让你看见并掌控 AI 如何理解你”。

## 核心产品原则

1. 把信任设计成功能：每条深层理解都标记为“可能”，用户可点击“说得对 / 不太对”。
2. 用户拥有记忆：画像可查看、修改、删除，不以隐式评分制造权威感。
3. 不诊断、不过度承诺：界面明确说明这是自我反思与行动支持工具，不是心理治疗或紧急服务。
4. 以行动而非依赖为目标：每次对话最后形成一个 5 分钟内能完成的行动。

## MVP 体验流程

### 1. 首次信任引导

三张简短的入门卡片：“你决定我记住什么”、“我会区分你说的事实和我的推测”、“你可以随时纠正或清除”。用户点击“开始一次真实的对话”进入主界面。

### 2. 陪伴对话主界面

主视觉是一个抽象、中性、柔和的“未来自我”虚拟智能体。智能体会呼吸、眼神移动、眨眼，并根据“倾听 / 思考 / 回应”三种状态改变表情、光晕与动作。

底部为对话控制器：麦克风按钮可开始/停止模拟语音输入，输入过程显示波形与逐字字幕；也可打字发送。Demo 内置一条高质量演示剧情，可完整展示听见、求证、画像更新和微行动。

### 3. “我是这样理解你的”解释层

对话后以底部抽屉显示三层信息：

- 你告诉我的：用户原话中的事实。
- 我正在猜的：不确定的情绪/需求推测，带“说得对 / 不太对”。
- 我想记住的：拟加入长期画像的信息，需用户确认。

### 4. 画像与成长

次级页面显示“我重视什么”、“什么会消耗我”、“什么能帮到我”、“我最近在练习什么”。避免使用伪科学的“人格完整度”百分比，改用可追溯的记忆条目和用户确认状态。

## 信任与留存机制

- 首日价值：用户在第一次对话后得到一句准确的反映和一个小行动。
- 持续价值：每次对话让“价值观—触发因素—有效行动”更准，下次对话会引用用户确认过的记忆。
- 健康留存：不做连续签到压力，改为“今天值得被记住的一件事”和对过去行动的轻量回访。

## 商业模式与壁垒

推荐 Freemium：免费版提供每日一次深度对话和基础画像；付费版提供无限对话、长期记忆、周度反思、情境预演与个性化声音。不出售用户隐私，不以广告变现。

真正壁垒不是通用对话 UI，而是：用户主导的长期记忆图谱、“理解→求证→行动→回访”的闭环数据、通过纠错学到的个人语义、以及用户对可控记忆的长期信任。

## 前端架构

- React + Vite + TypeScript。
- 手机优先的单页 Demo，包含入门、对话、画像三个界面状态。
- CSS/SVG 动画实现中性虚拟人物，不依赖后端或外部 API。
- 用本地状态模拟语音识别、AI 思考、字幕流、画像确认与微行动完成。
- localStorage 保留入门和用户确认结果，同时提供一键重置 Demo。

## 视觉系统

保留参考图的暖白、沉静、大量留白与柔和金色光感，但改造为更有生命感的深色对话舞台：深墨蓝背景、薄荷绿呼吸光、珊瑚色情绪点，以柔和米白内容面板承载需要阅读的信息。不使用过多仪表盘卡片。

## 验收标准

1. 390×844 手机视口无水平溢出，主操作在首屏可达。
2. 虚拟人物具有呼吸、眨眼及三种对话状态反馈，并支持 `prefers-reduced-motion`。
3. 用户可走通“开始→说话/打字→看字幕→看 AI 理解→纠正/确认→接受小行动”。
4. 画像页可看见条目来源、信心类型与删除/编辑入口。
5. 项目可构建，并通过浏览器完成核心路径验证。
